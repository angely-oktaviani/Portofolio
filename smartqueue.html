SmartQueue: Real-Time Clinic Live Ticket System

Menghilangkan penumpukan antrean fisik di fasilitas kesehatan primer melalui arsitektur komunikasi WebSocket dua arah dan antarmuka mobile yang intuitif.

01. The Problem Space

Sistem antrean konvensional memaksa pasien menunggu di ruang tunggu yang sempit dalam durasi tidak menentu. Hal ini meningkatkan stres pasien dan risiko penularan infeksi silang di lingkungan klinik.

02. Design Decisions & Visual System

Hierarki visual dipusatkan pada keterbacaan nomor antrean, kontras warna yang nyaman, serta alur tanpa hambatan (*zero-friction* tanpa perlu registrasi akun rumit).

03. Engineering Architecture & Codebase

Menggunakan WebSockets (Socket.io) untuk transmisi data dua arah secara instan antara loket admin dan perangkat pasien tanpa membebani server dengan *HTTP polling*.

server/sockets/queueHandler.js
Node.js • Socket.io 
// 1. Inisialisasi Modul & Dependencies
const express = require('express');
const http = require('http');
const { Server } = require('socket.io');

const app = express();
const server = http.createServer(app);
const io = new Server(server, {
  cors: { origin: "*", methods: ["GET", "POST"] }
});

// 2. Handler Koneksi WebSocket Real-Time
io.on('connection', (socket) => {
  console.log(`[Socket Connected]: ${socket.id}`);

  // Pasien bergabung ke ruang antrean klinik
  socket.on('join-clinic-room', ({ roomCode }) => {
    socket.join(`clinic-${roomCode}`);
  });

  // Petugas loket memanggil nomor antrean berikutnya
  socket.on('call-next-ticket', async (payload) => {
    try {
      const { clinicId, officerId } = payload;
      const nextTicket = await advanceQueue(clinicId, officerId);

      // Broadcast nomor tiket terbaru ke seluruh pasien secara live
      io.to(`clinic-${clinicId}`).emit('queue-updated', {
        currentTicketNumber: nextTicket.number,
        targetRoom: nextTicket.room,
        estimatedWaitTime: nextTicket.estimatedMinutes,
        updatedAt: new Date().toISOString()
      });
    } catch (err) {
      socket.emit('queue-error', { error: 'Gagal memproses antrean.' });
    }
  });

  socket.on('disconnect', () => {
    console.log(`[Disconnected]: ${socket.id}`);
  });
});

server.listen(5000, () => {
  console.log('SmartQueue WebSockets active on port 5000 🚀');
});

04. Key Takeaways

Menyinkronkan desain UI modular dengan transmisi event WebSocket menghasilkan pengalaman pemantauan nomor antrean tanpa jeda dan menghilangkan kekhawatiran nomor terlewat.
